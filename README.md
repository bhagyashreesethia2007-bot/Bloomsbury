# BloomsBury Book Store

Welcome to **BloomsBury Book Store** — a simple online bookstore website made using HTML and CSS.

I created this project as a beginner web development project to practice building a complete webpage.

# About the Project

The idea behind BloomsBury is to create a small online bookstore where readers can explore different genres of books in one place.

The website includes books from categories such as:

*  Fiction
*  Romance
*  Mystery
*  Self-Help
*  Academic
*  Fantasy

Each book has its title, author, short description, price, and an Add to Cart button.

# Features

* Simple and vintage bookstore design
* Navigation bar with different sections
* Hero section with featured books
* About Us section
* Categories section
* Books collection
* Individual book cards
* Book prices and descriptions
* Contact form
* Footer 
* Responsive layout for all types of screens

The navigation connects the main sections of the website such as Home, Books, Categories, About, and Contact.

# Technologies Used

* HTML – Used to create the structure of the website
* CSS – Used for styling, layouts, colors, spacing and responsiveness

No JavaScript or backend has been used in this version.

# Design

I wanted the website to have a warm , vintage , bookish feeling, so I used mostly **brown, beige, and cream colors**.

The CSS uses Flexbox and Grid for arranging the navigation, hero section, categories, and book cards. It also includes media queries so the layout changes on smaller screens.


# Responsive Design

The website has responsive CSS for different screen sizes.

On smaller screens:

* The navigation becomes vertical
* Category cards change their layout
* Book cards become single-column
* Book images become wider
* Hero content is stacked vertically

This helped me understand how websites can adapt to different screen sizes.

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`
4. Run it using a browser or the **Live Server** extension in VS Code.
